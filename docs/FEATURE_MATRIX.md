# Nexora ERP feature matrix — Phase 1 baseline

**Purpose.** This is the scope and traceability baseline for Phase 1. It catalogs the broad Nexora target raised in the Phase 1 brief and requirements suggested by the public Wings ERP Classic and ERP EA pages. The catalog is intentionally broader than the current application. It does not claim exhaustive knowledge of Wings' proprietary product. Product-page claims are reference candidates, not evidence that Nexora has those capabilities or that a feature is required by every Nexora deployment.

**Research references:** [Wings ERP Classic](https://www.wingsinfo.net/wings-erp-classic.php) describes sales, purchases, accounting, inventory, budgeting, production, GST, payroll, fixed assets, branch operations, reports and related tools. [Wings ERP EA](https://www.wingsinfo.net/wings-erp-ea.php) adds a retail/distribution focus including POS, serial/batch handling, centralized purchasing and delivery, repairs, installations, loyalty and related flows. Reconfirm feature availability and jurisdictional details with Wings/current business owners before treating any vendor-page statement as a requirement.

## Status and evidence rules

| Status | Meaning |
|---|---|
| **Implemented and previously verified** | Present in source and documented by an earlier test/verification report. The current environment could not rerun that evidence. |
| **Implemented, not freshly verified** | Current source has the route/model/template or service, but no current behavioral run was available for this review. |
| **Partial** | A usable slice exists, while named parts of the expected journey or controls are absent. |
| **Missing** | No corresponding user workflow was found in project routes/templates/services. A model alone does not count as a workflow. |
| **Defective / inconsistent** | Existing behavior or documentation disagrees with the target or another implementation. Phase 1 records it; it does not repair business behavior. |
| **Unknown / decision needed** | Scope, accounting policy, role, jurisdiction or acceptance rule cannot be safely inferred. |

## Confirm before implementation

1. Which of the retail/distribution, manufacturing, HR/payroll, CRM/service, projects, import/export, POS, batch/serial, bins and inter-branch features are actually in the first product release?
2. What organization/branch role vocabulary is authoritative, and which roles may prepare, approve, post, reverse and export each document?
3. Which GST reporting outputs are needed for internal review, and is portal/e-invoice/e-way-bill integration in scope? Internal reports currently do not file or certify returns.
4. What stock-count, negative-stock, reservations, unit-conversion and serial/batch policies apply?
5. Which accounting policies govern cash-flow classification, GRNI, landed costs, purchase price variance, fixed-asset acquisition and statutory depreciation?
6. Which source documents and APIs, bank formats, email/SMS providers and deployment database are required?
