# Nexora ERP screen inventory — Phase 1 baseline

This inventory separates **current screens** (every row in the first table is route-backed) from **proposed screens** (every row in the second table lacks a first-party user-facing workflow). A model or Django admin capability is not counted as a Nexora screen. Paths marked **proposed** are navigation design targets, not live URLs. Each screen title states its purpose; the table specifies its data/actions, access and acceptance link. The shared shell and interaction rules in `UI_UX_SPECIFICATION.md` apply to every record below. Unsuffixed family references in other documents map to the route variants here: `SCR-SAL-03` = `SCR-SAL-03-L/F/D` plus proposed `SCR-SAL-03-E`; `SCR-SAL-04` = `SCR-SAL-04-F`; `SCR-SAL-05` = `SCR-SAL-05-L/F/D/FD`; `SCR-PUR-03` = `SCR-PUR-03-L/F/D`; `SCR-PUR-04` = `SCR-PUR-04-F/E/D`; `SCR-PUR-05` = `SCR-PUR-05-L/F/D/FR`.
